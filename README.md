## Wallora - Discover Wallpapers That Inspire You !
Wallora is a modern, responsive wallpaper discovery website designed to help users explore, preview, and download beautiful wallpapers for mobile phones and desktops.

Featuring a premium dark theme, elegant UI, and a Pinterest-inspired image grid, Wallora makes discovering your next favorite wallpaper simple and enjoyable.

## ✨ Features

- 🎨 **Modern Dark UI** - Minimal design with a black background, clean typography, and subtle hover effects.
- 🖼️ **Wallpaper Gallery** - Browse stunning wallpapers in a responsive, Pinterest-inspired image grid.
- 🔍 **Search Wallpapers** - Find wallpapers easily by title or category.
- 🗂️ **Explore Categories** - Discover wallpapers across 12 categories: Nature, Mountains, Cars, Anime, Gaming, Space, Minimalist, Abstract, Animals, Aesthetic, Technology, and Architecture.
- 📱 **Device Filters** - Filter wallpapers by mobile or desktop format.
- 🔥 **Popular Wallpapers** - Explore featured and popular wallpaper collections.
- 🆕 **Recently Added** - Discover the latest wallpaper additions.
- 👁️ **Wallpaper Preview** - View larger wallpaper previews and image details before downloading.
- ❤️ **Favorites** - Mark your favorite wallpapers for quick access.
- ⬇️ **Download Wallpapers** - Access download controls for supported wallpaper images.
- 📱 **Responsive Layout** - Enjoy a consistent experience on mobile phones, tablets, and desktops.
- ✨ **Smooth Interactions** - Experience clean transitions, subtle animations, and interactive elements.

## 🛠️ Tech Stack

- 🌐 **HTML5** - Provides the structure of the website using semantic and accessible HTML elements.
- 🎨 **Tailwind CSS v3 (Play CDN)** - Creates responsive layouts, utility-based styling, and consistent UI components.
- 🖌️ **Custom CSS3** - Adds custom styling, dark theme colors, rounded corners, hover effects, transitions, and glassmorphism.
- ⚡ **Vanilla JavaScript (ES6+)** - Powers interactive features such as wallpaper search, category filtering, preview modals, favorite buttons, and UI notifications.
- 🔤 **Google Fonts** - Provides modern typography for a clean and premium visual experience.
- 🎯 **Material Symbols / Inline SVG Icons** - Adds icons for navigation, search, favorites, downloads, and other interface elements.
- 🖼️ **External Image URLs** - Supplies wallpaper images for galleries, category cards, and previews.
- 💻 **Visual Studio Code** - Recommended editor for writing and managing the website code.
- 🌿 **Git & GitHub** - Used for version control, source code management, and project hosting.
- 🚀 **GitHub Pages** - Enables static website deployment directly from a GitHub repository.

### 🏗️ Architecture

- 📄 **Static Website** - Built with HTML, CSS, and JavaScript without requiring a backend server or database.
- 📱 **Responsive Design** - Adapts the interface to mobile phones, tablets, and desktop screens.
- 🧩 **CDN-Based Resources** - Loads Tailwind CSS, fonts, and other external resources through content delivery networks.
